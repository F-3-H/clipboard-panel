# 剪贴面板（Clipboard Panel）

一个常驻电脑桌面的悬浮面板：**白色半透明气泡风格**，左侧是剪贴板历史，右侧是电脑图片相册，中间分隔条可拖动调节两区大小，方便把剪贴图片直接拖进相册。

## 功能

### 📋 剪贴板（左侧气泡）
- 自动记录你**复制 / 剪切**的文本与图片（含从资源管理器复制/剪切的图片文件）
- **最近 20 秒内剪切的项会高亮**（深色蓝底 + 左侧竖条），一眼看到最新内容
- **🏷 标签分类**：把鼠标移到任一条记录上，点 🏷 即可给它标注标签；顶部标签栏显示所有标签及数量，点击标签只看该分类的内容，点 × 删除标签
- 每条记录支持：
  - **⧉ 复制**：一键复制回剪贴板
  - **★ 置顶**：标记重要内容，置顶项永远排在最前、清空时保留
  - **✕ 删除**：移除单条记录
- 顶部搜索框即时过滤历史；「清空」保留置顶项清空其余

### 🖼 相册（右侧气泡）
- 默认扫描系统「图片」文件夹，点「＋ 文件夹」可加入更多目录
- 缩略图墙展示，鼠标悬停可 **🏷 标注标签 / 复制图片 / 打开 / 删除**（仅内置相册中的图片可删除）
- **🏷 标签分类**：把鼠标移到某张图片上，点 🏷 给它标注标签；相册顶部标签栏显示所有标签及数量，点击标签只看该分类的图片，点 × 删除标签
- **拖入即加入相册**：
  - 把左侧剪贴板历史里的图片卡片**直接拖到右侧相册**，松开即加入
  - 从资源管理器把图片文件拖进面板任意位置也会加入
  - 拖入的图片保存在「内置相册」目录，原图删除也不影响

### 🪟 面板操作
- **白色半透明毛玻璃外观**（Windows 11 自动启用 acrylic 效果；Win10 回退为浅色背景）
- **收缩成长条**：点标题栏「▁」按钮，面板立刻缩成一条细长条，点击「▸」展开恢复
- **自定义大小**：拖动窗口四边任意位置自由缩放（上下左右都可以）；设置里另有 小/中/大 三档预设
- **两区比例可调**：拖动两个气泡中间的竖条，左右区大小随心分配；双击分隔条恢复均分
- **🎨 多种风格**：设置里点⚙可切换五种面板风格（波普 / 日系可爱 / 纸质手账 / 复古报刊 / 气泡聊天），切换自然过渡，选择会被记忆
- **💧 自定义透明度**：设置里拖动「面板透明度」滑杆，可让整个面板半透明透出桌面
- 剪贴板记录做成**聊天气泡造型**（圆角气泡 + 左下小尾巴 + 右下角时间戳，悬停浮现操作按钮）
- 标题栏：📌 面板置顶（钉在所有窗口之上）、⚙ 设置、最小化、关闭
- 窗口位置、大小、两区比例、置顶状态、折叠状态、当前风格、透明度全部自动记忆，重启恢复

## 使用

1. 双击 **`install.bat`** 安装依赖（仅首次需要，自动使用国内镜像下载 Electron）
2. 双击 **`启动剪贴面板.bat`** 打开面板

> 也可以命令行运行：`npm start`（开发调试用）

## 数据存放位置

所有数据保存在本机用户目录：`%APPDATA%\clipboard-panel\`
- `clipboard.json` — 剪贴历史
- `images\` — 剪贴板图片
- `album\` — 内置相册（拖入的图片）
- `thumbs\` — 相册缩略图缓存
- `settings.json` — 面板设置（窗口位置/大小/两区比例/折叠状态等）

> 提示：设置环境变量 `CLIP_PANEL_DATA_DIR` 可把数据目录改到别处（便携模式）。

## 技术说明

- Electron 无边框窗口（`frame: false` + `-webkit-app-region: drag`），`backgroundMaterial: 'acrylic'` 毛玻璃
- 主进程每 800ms 轮询剪贴板，文本与图片分别去重（图片按 PNG 内容哈希）
- 支持检测资源管理器复制/剪切的图片文件（`FileNameW` 剪贴板格式）
- 渲染层通过 `contextBridge` 安全桥接，`dsp://` 自定义协议提供本地图片访问
- 相册缩略图用 `nativeImage.createThumbnailFromPath` 生成并缓存，大目录也不卡
- 页面 JS 出错会在面板顶部显示红色错误条，并写入 `debug.log`，便于排查
